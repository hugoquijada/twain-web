# Ejemplo JavaScript

Este ejemplo importa `../../javascript-client/src/index.js`. Para que el navegador pueda resolver esa ruta, inicie el servidor HTTP desde la raíz del repositorio:

```powershell
cd C:\ruta\devicebridge
python -m http.server 8080 --bind 127.0.0.1
```

Luego abra `http://127.0.0.1:8080/examples/javascript/`.
